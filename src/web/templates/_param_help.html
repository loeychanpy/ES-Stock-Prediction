NPMM & Toleransi

NPMM mengukur seberapa dekat harga penutupan dengan minimum lokal N hari sebelumnya. Sistem mengambil Low terendah dari N hari sebelum hari ini (hari ini tidak ikut dihitung) sebagai acuan.

Toleransi adalah lebar pita di sekitar acuan tersebut, diukur dua arah:

|Close − Acuan| ≤ Acuan × {{ near_txt }}%

Sedikit menembus ke bawah masih dianggap wajar (false breakdown), tetapi jika tertembus lebih dalam dari toleransi, support dianggap gagal. Contoh: acuan 5.000 dengan toleransi 3% → pita 4.850–5.150.

Take Profit & Stop Loss

TP dan SL dihitung dari ATR (14), yaitu rata-rata rentang pergerakan harga harian. ATR dipakai agar jarak target menyesuaikan volatilitas saham, bukan angka rupiah yang tetap.

TP = Harga acuan + ({{ tp_txt }} × ATR)  •  SL = Harga acuan − ({{ sl_txt }} × ATR)

Harga acuan: Close hari sinyal di dashboard, dan Open hari berikutnya saat backtest (bebas look-ahead). Dengan setelan sekarang, potensi untung {{ tp_txt }}× risiko ({{ tp_txt }} : {{ sl_txt }}), sebelum fee. ATR diambil dari hari sinyal, jadi TP dan SL tidak berubah selama posisi terbuka.

Akibat tiap nilai (hasil uji 3 saham, data ±3 tahun)

Setelan aktif: N = {{ params.n_days }} hari, toleransi {{ near_txt }}%, TP {{ tp_txt }}×ATR, SL {{ sl_txt }}×ATR. Angka berikut adalah rata-rata BBCA, BBRI, dan TLKM; parameter lain memakai nilai default saat satu parameter diuji. Default 5 hari dipilih karena mewakili satu minggu bursa, dan 3% karena kira-kira selebar satu ATR harian — keduanya berada di tengah rentang yang paling seimbang di bawah ini.

N-Hari Min Low (default 5 hari)

2–3 hari Low cepat berubah; sinyal naik ke 55, return 11,9%, drawdown −11,1%. Rawan terpicu noise 1–2 hari.
4–7 hari Disarankan Satu minggu bursa; 49 sinyal, win rate 52,6%, return 10,8%, drawdown −10,7%.
8–15 hari Low lebih dalam dan stabil; sinyal turun ke 31, win rate 54,0%, tetapi return 7,9% karena entry makin telat.
>15 hari Low sudah lama; sinyal tinggal 20, win rate 43,9%, return 4,9%. Banyak peluang terlewat.

Toleransi (default 3%)

0,5–1% Terlalu ketat: hanya 6 sinyal, win rate 22,2%, return −1,1%. Harga jarang menempel persis di low.
2% Selektif: 22 sinyal, win rate tertinggi 61,9%, return 6,3%. Cocok untuk saham yang pergerakannya tenang.
2–3% Disarankan 3% kira-kira 1×ATR harian: 49 sinyal, win rate 52,6%, return tertinggi 10,8%, drawdown −10,7%. Masih ada ruang untuk wick.
>3–5% Mulai longgar: 4% → 62 sinyal, win rate 48,1%, return 7,4%; 5% → 74 sinyal, win rate 42,6%, return 1,7%, drawdown −14,5%.
>5% NPMM nyaris tidak menyaring: 10% → 92 sinyal, win rate 37,6%, return −7,6%, drawdown −19,1%. Harga yang sudah jauh dari low ikut dianggap dekat.

Take Profit (default 2×ATR)

1× Cepat kena TP: win rate 67,4%, tetapi return hanya 7,8% karena untung per transaksi kecil.
1,5–2,5× Disarankan 2× (default): win rate 52,6%, return tertinggi 10,8%, drawdown −10,7%; rasio 2:1 terhadap SL.
3× Butuh pergerakan lebih besar: win rate turun ke 34,3%, return 2,9%, drawdown −15,9%.
≥4× TP jarang kena: win rate 26,6%, return 2,6%, drawdown −16,7%; banyak posisi ditutup SL atau akhir data.

Stop Loss (default 1×ATR)

0,5–0,75× Stop terlalu rapat: sering kena noise; win rate 34,8–39,5%, return 2,3–2,9%.
1× Disarankan Win rate 52,6%, return 10,8%, drawdown −10,7% — kombinasi terbaik pada pengujian ini.
1,5× Lebih tahan noise: win rate naik ke 60,9%, tetapi return turun ke 4,8% dan drawdown melebar ke −16,9%.
≥2× Risiko per transaksi terlalu besar: return 1,2%, drawdown −18,7%. Satu kerugian menghapus beberapa keuntungan.

Ringkas: N 4–7 hari, toleransi 2–3%, TP 2×ATR (1,5–2,5× masih wajar), dan SL 1×ATR adalah rentang yang paling seimbang pada pengujian ini. Toleransi 1% terlalu ketat (hampir tidak ada sinyal), sedangkan di atas 3% sinyal memang bertambah tetapi win rate dan return cenderung turun serta drawdown membesar. Angka uji memakai fee 0,15% beli dan 0,25% jual, dan bisa berbeda untuk saham lain — selalu cek hasilnya di halaman Backtest sebelum memakai setelan baru.
